# ☕ Sistema Bancário em Java

Projeto desenvolvido durante o curso **Java: criando sua primeira aplicação**, da [Alura](https://www.alura.com.br/).

A aplicação simula um sistema bancário simples, permitindo consultar saldo, realizar transferências e receber valores por meio de um menu interativo no terminal.

## 🚀 Funcionalidades

- **Consultar saldo:** exibe o saldo atual da conta.
- **Transferir valor:** permite realizar transferências, verificando se existe saldo suficiente.
- **Receber valor:** adiciona um valor ao saldo da conta.
- **Sair:** encerra a aplicação.

## 🛠️ Tecnologias utilizadas

- Java
- Scanner (`java.util.Scanner`)
- Estrutura de repetição `while`
- Estruturas condicionais (`if` e `else if`)
- Manipulação de variáveis e operações matemáticas

## ▶️ Como executar

**1.** Certifique-se de ter o Java instalado.

**2.** Clone o repositório:

```bash
git clone https://github.com/HenzoWeelthyner/java-primeira-aplicacao.git
```

**3.** Entre na pasta do projeto:

```bash
cd java-primeira-aplicacao
```

**4.** Compile o arquivo:

```bash
javac -d out src/Desafio.java
```

**5.** Execute a aplicação:

```bash
java -cp out Desafio
```
